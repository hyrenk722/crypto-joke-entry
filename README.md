Entry for the make.fun competition "Laugh Track: The Crypto Trading Joke Contest": one joke about
crypto and trading life, a single line under 200 characters. `main.py` writes that joke
to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validating the
gate first: UTF-8 text, 1–200 characters, not only whitespace, exactly one
line — then reading the file back to verify the written bytes match.

> I bought the dip at $60K, averaged down at $40K, and now my cost basis is the only thing in my life that's consistently going up.

Why this joke: it is true to trading life twice over — buying the dip and averaging down are
things every crypto trader has actually done — and the turn inverts the one thing a trader
wants to go up: the price keeps falling while the cost basis, the number that is supposed
to fall, is the only thing consistently rising. Two concrete prices anchor it in real
trading, the punchline lands on the last word, and the whole line reads cleanly aloud in
one breath.
